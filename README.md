# Everloot protocol

The shared contract between every Everloot part: what an upload may contain, what the API returns and what the MCP tools accept.

## What it holds

- Upload record kinds and their limits
- Public API response shapes, including the attribution block
- MCP tool input and output schemas, as JSON Schema and TypeScript types (to be published on npm as `@everloot/protocol`)

## Status

Not moved yet. WoW: Forever launches on November 4, 2026; until then this code lives in
[Everloot/everloot](https://github.com/Everloot/everloot). It moves here after launch, with its history, following the
organization split plan.
